# 实验室要收回上万亿投入，别在它们的流沙上盖楼

*在 AI Engineer NYC 2026 上，Nous Research CEO Dillon Rolnick 认为，面对模型商品化，AI 实验室要么把客户锁住，要么直接和客户竞争；Rolnick 呼吁企业在 Hermes Agent 这样的开放地基上构建自己的 agent。*

**Featured Keynote · 2026 年 10 月 13 日（周二）· 5:06–5:24pm · Simons Room (Metropolitan East)，Main Stage**
**讲者：** Dillon Rolnick，CEO，Nous Research

---

Dillon Rolnick 讲的是当天 Main Stage 的最后一场。「今天我们要谈的是，在你真正拥有的地基和平台上构建，」Rolnick 说，然后抛出整场演讲围绕的问题：「How do you make back a [trillion]-dollar infrastructure and research bet?」（一笔[万亿]美元级别的基础设施和研究押注，怎么收回来？）（字幕写作「centillion」；Rolnick 后面多次说的是「trillion dollar」投资。）各家实验室各自已经花了数千亿美元，打造越来越复杂的系统，「整个行业花掉的也许是数万亿」。

官方简介只有一句：「Modern businesses require open agents.」

## 1. 模型在商品化

「问题在于，模型已经开始商品化了，」Rolnick 说。实践者凭直觉就知道：大家会在 Astra、Fable、Opus、Kimi 之间随手切换，「不太在意背后是谁」，因为想试新模型。Rolnick 提到那一周 Twitter 上流传的图表：token 平均成本在降，token 总花费在猛涨，而服务这些 token 的基础设施成本持平。以前高性能模型里有利润空间，现在随着竞争让基础水平的智能随处可得，这块空间在收窄。

## 2. 收回投入的两条路

Rolnick 说，花了这么多钱而模型又在商品化，要收回来有「两条相当明显的路」。一是「换一层去竞争：往下做基础设施，或者往上贴近用户」。二是「build God，比谁都快地 build God，然后把 God 变现」。

![换一层竞争，或者 build god](../../slides/10-13-1706-hermes-gives-you-wings-build-on-open-fou/01.jpg)
*「1. Compete at a different layer 2. Build god」*

第一条路：站在用户面前就有粘性，「而粘性意味着利润」，所以竞争转到了 agent layer。「不过消费者善变，是很糟糕的客户。」企业在 token 上花很多钱，而且这些 token 有经济产出，所以 user layer 的仗会打到企业里，最好的位置是嵌进一家企业：「一旦进了企业，就很难被拿掉。」

接着 Rolnick 请听众设想两三年后的自己公司：按产出算，有多少劳动力是 agentic 的？「保守说 70%，大概更多。」如果 70% 的劳动力由一个「可能和你利益相悖的人」来组织，「他们可以被组织起来罢工」。Rolnick 说，一家要收回上万亿美元的实验室，会「动用你的不对称筹码……改写游戏规则」。

## 3. 如果造出了 God，就对准钱

第二条路：「如果你成功 build 了 God，你会把 God 对准世界上最赚钱的问题。收回投入的最好办法，不是以越来越薄的利润把它卖给别人去解决这些难而赚钱的问题……最好的办法是自己去解决。」

![The best shot at earning it back](../../slides/10-13-1706-hermes-gives-you-wings-build-on-open-fou/02.jpg)
*slide 上写的是「point the models」；Rolnick 在台上说的是「point God」。*

「实验室认为市场是可解的问题，它们就是这么看金融行业的，」Rolnick 说：一个 tractable 的问题，「也许甚至不算很难」。聪明的实验室知道自己在金融上缺 context、know-how 和经验，单干不行，所以眼下雇投行分析师，和全球最大的一些机构合作。「我相信它们最终会直接去源头，因为……钱在那里。」

## 4. 地基一旦选定就会固化

「在座各位需要 AI，」Rolnick 说。大家都见过 agentic system 能做什么，「回不去了」。在场的 VP、高管和工程师现在就得决定在哪些工具和流程上「扎根」。无论选了什么都会固化：组织会围绕它积累 know-how、建立流程和系统。

「I implore you, do not build on quicksand foundations. Build on open foundations. Build on Hermes Agent.」（我恳请各位，别在流沙上打地基。在开放的地基上构建。在 Hermes Agent 上构建。）

![Don't build on quicksand](../../slides/10-13-1706-hermes-gives-you-wings-build-on-open-fou/04.jpg)
*「Don't build on quicksand.」*

## 5. 为什么由 Nous 来说这些

「我刚花了不少时间，希望已经说服了各位：现在 AI 领域期望值最高的做法，要么是把你们套住然后抬价，要么是直接取代你们，」Rolnick 说，「那我为什么站在这里？」

Rolnick 的回答是，Nous Research「主要是出于道德和哲学上的理由」创立的。商业里道德和激励常常不一致，「这时候最省事的是改掉你的道德」。Nous 则认为最好的路是公司和用户利益一致。公司创立的初衷是对抗「一种看似不可阻挡的趋势：走向集中，走向对」Rolnick 所说的也许是世界上最重要的技术的「集中控制」。「Nous Research 是由一群 nerd 创立、由 nerd 组成的。热爱科幻的 nerd，」Rolnick 说，「Skynet was, after all, a closed source company.」（说到底，Skynet 是一家闭源公司。）

## 6. 软件不再有护城河

「专有软件已经没有真正牢固的护城河了。复制一个软件的边际成本已经暴跌。」Rolnick 举的例子是：几个月前 xAI 发布了 Grok Bot，Nous 觉得它的界面很好。「于是我们把 Hermes Agent 对准它，一个周末就复刻出来，作为 Hermes Agent 的一个功能发布了，当然是开源的。」（8 月有行业报道说 Nous 在公开测试 Hermes Agent 的「Bot Mode」插件，设计跟随 Grok Bot；「一个周末」只来自演讲本身。）

Rolnick 说，以前做软件很难：协调好的工程团队花很长时间把开源库拼成专有产品，再当 SaaS 卖。「但现在正好反过来。任何东西都能被逆向工程」，很多有动力的开源开发者正把自己的 agent 对准商业软件。「The moats of yesterday were in proprietary IP. The moats of tomorrow are in network effects, reputation, and reliability.」（昨天的护城河在专有 IP。明天的护城河在网络效应、声誉和可靠性。）

## 7. 模型也一样

Rolnick 说，实验室往往低估自己的工具，或者低估使用这些工具的人。在模型这边，「一个模型可以相当容易地把另一个模型教得几乎和原模型一样聪明」，模型的优势很少在架构，「通常在数据质量和规模」。

停顿片刻后，Rolnick 讲了实验室的应对。「它们把教的过程叫 distillation，把非法的 distillation 叫盗窃。你不能把那叫侵犯版权，因为侵犯版权意味着你拿了每一个活着的人写下的或创作的作品，然后在上面训练。」而且「它们还训练模型不去协助训练别的模型，并把这叫作 safety」。Rolnick 没有点名哪家实验室。

## 8. Agent 是操作系统，不是 chatbot

「Agent 像操作系统、像框架，比起 chatbot，它们更像前者，」Rolnick 说。把 agent 当私人助理，就「永远停留在表面」。

Rolnick 提到当天 Main Stage 稍早的一场演讲：一家金融机构如何把数据源、routine code、人的观点和 judgment 汇成投资决策。（Rolnick 没有点名；按直播顺序，最可能是 Coatue 的「A Hedge Fund as a Function」。）「Agent 的核心是一个把 determinism 和 non-determinism 结合起来的系统。」新的应用不必再是「冷冰冰的硬代码」，可以把 intelligence、reasoning 和 judgment 组合进去。

Rolnick 说，企业应该「在自己拥有的地基上」构建这些系统，能「随意换入换出想用的模型」，在代码、数据源、judgment、reasoning 这些原语上叠加功能。「但你们不该把整个生命都花在当一家智能公司上。」多数公司不是 agent 公司，也不是 AI 公司，应该专注于让自己成功的事。state of the art 变了，「你应该继承它，而不是重建、维护它」。

「记住，这些工具应该让你们变得更好，不是拿来替换你们的，」Rolnick 说，「你们知道造出一个人要耗多少能量吗？」

## 9. Hermes Agent 的主张

Hermes Agent 可以「想怎么跑就怎么跑，想在哪跑就在哪跑。按需要随便改。玩得不开心了，可以抱着球回家」。Rolnick 说，护城河「不再是把你困住。护城河在于声誉」。

Rolnick 的目标是建立一个标准。「Hermes Agent 今天是全世界使用和下载最多的开源 agent，」Rolnick 说，「下载量比一些闭源竞品高出一个[或几个]数量级」（这两个说法没有找到独立数据）。只要有一方愿意把这些工具开源，「水就会继续往低处流。我想待在低处，这样就能和你们一起，为世界上最好的开放 agent 配上支持、安全和可扩展性」。

Rolnick 的结尾：「总会有人收回我们投下的上万亿美元。确保那个人是你。……你可以拥有 state-of-the-art 的功能和可靠性，而不牺牲自主权。Build on something you own. Build with us.」（在你拥有的东西上构建。和我们一起构建。）
